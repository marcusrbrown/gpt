# .ai/AGENTS.md

Working notes, implementation plans, and research docs produced during AI-assisted development. Not shipped product docs — see [RFCs/](../RFCs/AGENTS.md) for those.

## Structure

```
.ai/
├── plan/    # Feature/refactor implementation plans (task checklists)
├── docs/    # Research notes, audits, pattern mapping docs
└── notes/   # Scratch notes (prompts, ideas)
```

## Conventions

- Plans use `TASK-NNN` checklist rows with status and completion date
- Keep notes dated and scoped to a single effort; don't let them go stale silently
- No secrets or credentials in any file here
- These are working documents, not authoritative specs — RFCs and AGENTS.md win on conflict
