# RFCs/AGENTS.md

Request for Comments documents for the local-first GPT creation platform. Sequential implementation specs, indexed by [RFCS.md](../RFCS.md).

## Structure

```
RFCs/
└── RFC-NNN-Title.md   # One RFC per major feature area, in implementation order
```

## Conventions

- Number RFCs sequentially (`RFC-001`, `RFC-002`, ...); never reuse a number
- Each RFC must fully land before the next one begins (see [RFCS.md](../RFCS.md) roadmap)
- Update [RFCS.md](../RFCS.md) when adding, renaming, or completing an RFC
- Keep RFCs focused on one feature area; link to related RFCs instead of duplicating context
